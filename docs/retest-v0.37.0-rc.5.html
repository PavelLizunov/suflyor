suflyor v0.37.0-rc.5 retest - STT resumes after Tera read-aloud

  1. Start a recorded session with Tera ru_f1 selected and confirm normal mic/system transcription before read-aloud.
  2. Read a long answer tile aloud. While Tera is playing, its speech must not appear in either mic or system transcript.
  3. Let Tera finish naturally. Speak a fresh phrase immediately afterwards. The phrase must appear in the transcript without waiting for the old character-count estimate to expire.
  4. Repeat while interrupting Tera with a second tile. A delayed terminal event from the first tile must not resume STT while the second tile is speaking.
  5. Repeat with Pause/Resume and Stop. Pause keeps STT suppressed, Resume keeps the same utterance active, and Stop resumes STT with a fresh buffer.
  6. Terminate the Tera sidecar during playback. STT must recover on protocol EOF; the log may contain event ids/reason tokens but no spoken text.
  7. Switch to Piper and confirm its conservative estimate fallback still suppresses read-aloud feedback.
