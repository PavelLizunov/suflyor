# Astra icon redesign — Slint MCP audit

## Scope

Before/after visual audit for the complete `slint-experiment/assets/icons/`
redesign. The visual concepts were generated by Astra and translated into the
production 16×16 SVG contract without changing button behavior or labels.

## Fixed capture conditions

- Target: `windows-worker` (`windows-brat` test VM)
- Build: `overlay-host`, debug, `--features ui-mcp`, locked dependencies
- Slint debug info: enabled during compilation and runtime
- MCP endpoint: local worker port 9123
- Window geometry: native defaults; Settings fixed at 720×600
- DPI: unchanged between each before/after pair
- Theme: Glacier unless a filename explicitly names another scheme
- Language: Russian primary pass; English semantic spot-check
- Data: synthetic or empty states only; no private transcripts, tokens, URLs,
  user paths, or real session titles in committed captures

## Candidate identity

The exact baseline and candidate commit SHAs, commands, exit markers, and
screenshot manifest are recorded after the Windows audit. Baseline images use
the parent of the candidate commit and matching runtime conditions.

## Required surfaces

- Overlay bar: default, active session, expanded state
- Help: icon legend
- Settings: all 16 tabs at 720×600
- Tile: default, menu open, playback controls
- Archive: list and row actions
- Transcript: controls and content actions
- Wizard and tray menu
- Theme spot-check: Glacier, Graphite, Obsidian, Light Frost
- Global hotkeys: one complete dispatch pass on the candidate binary
