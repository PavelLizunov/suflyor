# Overlay/tile state and stream terminals: bounded source contract

**Baseline:** `a10c356af05a5832a14ea06a5d0cb6c49694e3f1`. Actual selected Slint bindings and Rust event/caller paths inspected. **No application, Slint-MCP screenshots/hotkeys, Rust/network/concurrency/native execution.** Pure Python interleaving fixture is explicitly a source-operation model, not reproducing a Rust data race or user-visible leak. Original tile-C01/C03 remain hypotheses; tile-C02 markdown mechanism already source-confirmed, not changed here.

## Bar state is host-provided, not independent UI readiness

[Overlay properties](<../../../slint-experiment/ui/overlay_bar.slint#L506-L639>) cover timer/pause/capture/health/AI-streaming/backend/update/tts state. Defaults are display seeds, not real device/model health. [Callbacks](<../../../slint-experiment/ui/overlay_bar.slint#L641-L689>) are declaration surface; no blanket proof every callback is wired. [Timer/pause/stop](<../../../slint-experiment/ui/overlay_bar.slint#L847-L873>) only render when timer-active, invoke callbacks; [ask input chips](<../../../slint-experiment/ui/overlay_bar.slint#L932-L980>) allow text/manual/PTT while not confirming; PTT panel changed handlers release active recording when focus/state panel changes.

[Backend start/terminal pulses](<../../../slint-experiment/src/bin/overlay_host/tile_controller.rs#L709-L780>) increment/dec/reset atomic counter then schedule bar setters; new shared stream resets count because abort won't emit terminal. This is a UI pulse, not exact global active-task accounting across every independent PTT/vision request. [Session/health dispatch](<../../../slint-experiment/src/bin/overlay_host/tile_controller.rs#L847-L921>) sets timer/status/health mapping, checks active timer for AI-down status. Source channels and defaults do not prove native functional/timing/translation behavior.

## Tile actions and reused block binding reset

[Tile properties](<../../../slint-experiment/ui/tile.slint#L167-L192>) distinguish can-copy/raw body/conversation/followup busy; [changed blocks](<../../../slint-experiment/ui/tile.slint#L226-L244>) resets mark anchor/capture pending/mouse/select mode when model changes, **does not clear followup-busy**. [Submit helper](<../../../slint-experiment/ui/tile.slint#L263-L309>) busy/empty guard, callback invocation then clears text. Whitespace-only isn't Slint-empty guard; Rust trims before dispatch.

[Follow-up input](<../../../slint-experiment/ui/tile.slint#L1010-L1115>) visible only convo-id≥0, disables editor/send during busy, voice button remains enabled during recording for stop. Close button independent [chrome](<../../../slint-experiment/ui/tile.slint#L574-L590>). Copy via raw-answer/plain markup path or selected blocks is separate, earlier clipboard rejection unchanged. Source enabled property is not actual keyboard/focus/visual acceptance.

## Shared stream generation and original C01 preconditions

[install_streaming_tile](<../../../slint-experiment/src/bin/overlay_host/tile_controller.rs#L119-L149>) resets pulse, **increments generation before slot lock**, clears old tile busy via scheduled UI update, installs new slot. [GenGatedEvents](<../../../slint-experiment/src/bin/overlay_host/tile_controller.rs#L156-L190>) reads atomic generation, then calls inner.emit; all event/spawn channels gated, but generation check and slot mutation/use are not same critical section. Counterevidence: ordinary already-stale events blocked, new-followup init checks generation before dispatch; this substantially narrows but doesn't close concurrent check/act interval.

[Delta handler](<../../../slint-experiment/src/bin/overlay_host/tile_controller.rs#L537-L595>) locks **current** slot, appends text, throttles~25ms, captures tile/body, then schedules markdown/blocks without a second generation check in UI closure. Pure model demonstrates old gate pass → new install generation/slot → old inner handler reading new slot could append wrong body. This is the original `wave3_worker3_tile-C01` source precondition; no actual OS/Rust scheduling/closure delivery injection or native wrong-tile reproduction. Already-scheduled closure targets its weak tile, not necessarily the new slot, but can repaint old still-open tile after supersession. Which consequence occurs depends on where interleaving happens; do not conflate both mechanisms.

[Done/Error handler](<../../../slint-experiment/src/bin/overlay_host/tile_controller.rs#L596-L708>) takes slot, updates conversation turn/empty/error metadata, schedules final markdown/copy/busy=false. User-facing provider failure generic category while raw local error log remains separate. Missing tile/slot returns/no-op; conversation pruning/late closures not exhaustive acceptance. Delta reparses whole accumulated body at throttle/final; structural regex/parser count not semantic performance benchmark.

## Follow-up synchronous-init, terminal EOF and C03

[Follow-up entry](<../../../slint-experiment/src/bin/overlay_host/tile_followup.rs#L390-L477>) trims/rejects empty, looks up conversation; missing history paints generic expiry and clears busy before return. For valid history sets busy before endpoint/model preparation, clones old turns/commits user turn, sync clears/replaces UI streaming placeholder. [Dispatch](<../../../slint-experiment/src/bin/overlay_host/tile_followup.rs#L478-L624>) config snapshot, abort old shared ai_task, install new slot/generation, worker initializes MLX if needed, checks generation, invokes route ask and stores task handle. [MLX failure helper](<../../../slint-experiment/src/bin/overlay_host/mlx_lifecycle.rs#L141-L170>) clears busy; [PTT tile-error helper](<../../../slint-experiment/src/bin/overlay_host/tile_ptt.rs#L58-L78>) sets blocks/raw/copy only, **no busy=false**. They are not interchangeable error-state contracts.

[Backend ask loop](<../../../overlay-backend/src/runtime.rs#L1810-L1905>) forwards events/accumulates health/journal, breaks on explicit Done/Error. Receiver EOF simply exits loop then computes cost/journal; no synthesized terminal ai:event on EOF. `wave3_worker3_tile-C03` still requires producer/provider path that actually closes without terminal; state/source fixture does not reproduce that prerequisite. Explicit Done/Error and install supersession do clear busy, so “all failures stuck” is false. No watchdog/general EOF repair shown in this loop.

## PTT fixed sink and tile-close ownership limits

[PTT sink](<../../../slint-experiment/src/bin/overlay_host/tile_controller.rs#L201-L370>) stores fixed weak tile/convo rather than shared slot, per-sink accumulation/throttle and terminal busy reset; ignores malformed non-ai channel via delegate. It avoids shared current-slot latest-wins mapping, not all native closure/lifetime races. [PTT startup](<../../../slint-experiment/src/bin/overlay_host/tile_ptt.rs#L128-L150>) sets busy; [detached transcribe/ask](<../../../slint-experiment/src/bin/overlay_host/tile_ptt.rs#L254-L300>) not in shared ai_task, so repeated PTT independent. Selected source has no register_tile_stream call; close-abort comments do not establish registered cancellation for detached PTT. Device/model failures via ptt_tile_error may leave busy true until other path/close; no UI reproduction.

[Abort registry](<../../../slint-experiment/src/bin/overlay_host/tile_window.rs#L64-L120>) keyed synchronous tile-id, registration replaces prior handle/aborts it; negative id ignored, abort/close-all registered handles only. [Queued tile cap/close](<../../../slint-experiment/src/bin/overlay_host_windows.rs#L1919-L2027>) one spawn/tick, cap16 evicts oldest, aborts keyed request, removes conversation, saves closed snapshot, hides/removes; weak live UI closes. Queue-spawn cap isn't proof every direct tile opener shares same cap. [Manual close](<../../../slint-experiment/src/bin/overlay_host_windows.rs#L3358-L3387>) refuses pinned close, snapshots/aborts/prunes; pin/copy/voice state not all covered by queue model.

## Verification limits

No Rust execution, independent reviewer, UI screenshot or event-loop/async-task fault reproduction. Original C01/C03 identities/status remain hypotheses; source counterevidence and prerequisite model only. Other overlay/tile markdown rendering, accessibility/translation, geometry/selection/copy/edit modes and all caller interleavings remain partial; source ranges are navigation, not audited line credit.
