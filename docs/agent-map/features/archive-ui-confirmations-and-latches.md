## Rows and UI state contract

[Row/window declaration](<../../../slint-experiment/ui/archive.slint#L16-L39>) carries session-id plus formatted title/date/count/duration/matches/stars/presence booleans. [Formatting/status](<../../../slint-experiment/ui/archive.slint#L68-L145>) data model/local selection/rename/confirm indices and titles, busy/status/cloud flag. UI index state is not stable session-id identity. Placeholder unavailable distinguishes Store open failure from empty rows; no arbitrary API error string display.

[Keyboard](<../../../slint-experiment/ui/archive.slint#L155-L187>) Escape cancels resummary confirm→delete confirm→rename→close; Enter activates selected row if no modal/edit. [Search](<../../../slint-experiment/ui/archive.slint#L256-L306>) edited fires query immediately/no debounce, accepted activates local idx; summary/empty/unavailable text selected, busy progress only displays `retranscribe-status` while `retranscribe-busy`. Error status set outside busy is not independently rendered by this header path; native missing feedback remains untested.

[Rows/actions](<../../../slint-experiment/ui/archive.slint#L351-L429>) selected by idx, summary/transcript/buttons and hover edit hints; [resummary/delete](<../../../slint-experiment/ui/archive.slint#L534-L557>) hidden when busy or row lacks data. [Rename](<../../../slint-experiment/ui/archive.slint#L566-L620>) field shares global rename text/index, Enter/save callback idx, cancel; [modal scrims](<../../../slint-experiment/ui/archive.slint#L623-L721>) title snapshot but confirm callback current stored index. Scrim blocks user row input, not worker UI model update.

## Opener/store initial async list versus search

[Opener](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L3-L81>) existing visible toggle drops slot; hidden existing refreshes names/query/delete confirmation but language/cloud flags only set at fresh creation. [Fresh setup](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L83-L139>) captures active session id, recordings snapshot, ru bool, cloud-STT signpost, spawns thread to open Store/list300; cap assertion ties60px×rows under Skia32,767. Query error after successful Store open uses empty Vec (`unwrap_or_default`) not unavailable; failed Store open None→unavailable.

[Initial model delivery](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L123-L144>) worker schedules results then re-runs query if user typed. It can replace results after modal/action opened while existing rows delivered via query first. [Search](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L146-L212>) synchronous UI Store lock/query, summaries/names refreshed, recording-presence snapshot not rebuilt, selected index reset0 and rename index reset-1. **Confirm delete/resummary index/title not reset here**, no query/generation token for model delivery. Synchronous DB scan may stall UI; no performance/native test.

Snapshot flags are signposts, not actual dispatch identity: STT route resolves Config later per job. Changed provider/language/active session/recordings while archive stays open may differ from initial flags/guard; source bound, native lifecycle preconditions untested. F7 creates fresh window after close, store background open failure no persistent loop.

## Rename/delete confirmation identity and save boundaries

[Rename](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L250-L290>) index->current row, trims text, calls best-effort session_names::set, closes editor/requeries regardless result; [name sidecar/write wrapper](<../../../overlay-backend/src/session_names.rs#L65-L100>) can return Result in `_in` seam but default wrapper logs errors. Error/result not reflected here; disk/native behavior not executed. [Regenerate title](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L295-L349>) snapshots sid/transcript and local-only endpoint, async generates/persists, no in-UI busy/generation token; completion requeries current query, not old model.

[Delete request](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L357-L378>) checks captured active sid and row id then stores title/index only. [Confirm](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L380-L433>) clears modal, re-fetches **current** results[idx], checks active sid then calls destructive backend. Store lock scoped before requery avoids self-deadlock. It does not validate current row sid against displayed title's original sid. Pure model: rowsA/B, confirm idx0 titleA, worker replaces rowsC/A/B, confirm idx0 selectsC. Async initial/query source permits replacement; actual event ordering/user-visible wrong deletion/native data action **not reproduced**, no fix authorized. Duplicate titles aren't stable identity either.

The earlier comment “list can't change behind scrim” describes user interaction only, not async model replacement. Reference correctness comes from executable code, not assertion. Backend delete/idempotence covered separately; UI index-to-ID race preconditions open.

## Retranscription global latch and UI busy/error signposts

[Process latch](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L3-L18>) AtomicBool, not only per-window property; [start worker](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L479-L545>) current idx->sid, tries latch, if busy paints status but **does not set fresh reopened window busy=true**. Normal start sets busy/loading text, named-thread new Tokio runtime; RAII ClearBusy Drop resets global through unwind; weak UI progress callback discarded if window gone. Guard acquisition can prevent double job even though fresh UI controls remain enabled (source), not concurrency/native proof.

[Completion](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L550-L599>) coarse errors, busy false then status text and requery; current UI displays status only while busy, so finish/error message visibility not established (blocks/progress can hide after false). Thread-spawn error resets global/busy, generic text. Closing [callback](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L742-L759>) hides/drops archive slot, no task abort or latch reset; background process-lifetime job continues, lock returns on worker Drop.

[Overwrite request](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L602-L653>) existing conspect displays confirmation title/index, confirm forwards index into start; same current-row identity issue as delete. [View summary](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L655-L716>) default-loads saved conspect into read-only tile; if missing checks captured-active session and global latch, starts text-only run_meeting_summary after click. Cloud-STT upload signpost not relevant to text-only summary. Debrief saved tile independent [source](<../../../slint-experiment/src/bin/overlay_host/aux_windows/archive.rs#L718-L739>).
