# WSOLA streaming and playback: source algorithm/transport contract

**Baseline:** `a10c356af05a5832a14ea06a5d0cb6c49694e3f1`. Algorithm and callers manually inspected, test source intent read; **no Rust compile/test, listening, audio-device/model execution, profiling/allocation/pitch benchmark**. Structural/numerical intentions are not measured DSP quality or realtime acceptance.

## Processor geometry, correlation and errors

[Crate root](<../../../suflyor-wsola/src/lib.rs#L1-L14>) exports Wsola/StreamingWsola/Error, [error enum](<../../../suflyor-wsola/src/error.rs#L5-L17>) distinguishes ratio/input size/buffer/state. [Construction](<../../../suflyor-wsola/src/wsola.rs#L78-L115>) allocates crossfade tables, computes overlap from ratio; setter rebuilds ratio/overlap/tables [source](<../../../suflyor-wsola/src/wsola.rs#L156-L167>). [Near-unity overlap](<../../../suflyor-wsola/src/wsola.rs#L659-L674>) uses quarter segment within ±0.15, otherwise half. Raised-cosine constant amplitude/equal-power sin-cos are source options, not clipping/energy-quality pass.

[Process validation/output](<../../../suflyor-wsola/src/wsola.rs#L212-L291>) requires segment>0/overlap<segment/input≥segment/advance-output≥1. There is no explicit finite-ratio/all-input-finite check in this path; NaN/huge/negative cases are not exhaustively bounded by one comparison/cast. Target output float rounding and additions/memory demand remain native-unexecuted. [OLA loop](<../../../suflyor-wsola/src/wsola.rs#L293-L417>) bounds iterations, compression tail, fraction input/output alignment, normalized overlap, final trimming/padding and output capacity error; all native numerical branch/fault paths not accepted.

[Correlation selection](<../../../suflyor-wsola/src/wsola.rs#L439-L509>) uses direct search for candidate≤64 or overlap<32, FFT otherwise. [Plan/cache/workspace](<../../../suflyor-wsola/src/wsola.rs#L512-L637>) grows FFT plans/scratch/input/corr/prefix vectors, energy-normalizes conjugate correlation. [Direct normalized scan](<../../../suflyor-wsola/src/wsola.rs#L710-L791>) uses mean/variance energy epsilon and parabola. [Subsample helpers](<../../../suflyor-wsola/src/wsola.rs#L963-L1018>) clamp fractional peak offset and linearly interpolate. SIMD-friendly unrolling comments do not prove generated SIMD/native timing.

## Allocation claims narrowed to actual buffer gates

[API](<../../../suflyor-wsola/src/wsola.rs#L169-L209>) process() allocates output Vec; process_into disallows caller-output growth but internal output may grow; process_into_no_grow disallows growth of the main output buffer. reserve_output_capacity pre-reserves **output storage only**. Correlation still resize/allocate scratch vectors or FFT plans [source](<../../../suflyor-wsola/src/wsola.rs#L512-L637>) with no allow_internal_growth gate; thus “never grows all internal allocations / zero hot-path allocations” is **not established** by that API/source. No production simplification/optimization recommended solely from this check.

Streaming wrapper creates input Vec, calls allocating process(), split_off held tail, saves input tail. Transcript adapter likewise allocates each refill; native transports append output/stereo buffers/channels/mutex queues. It is not an allocation-free end-to-end audio pipeline.

## Streaming chunk/tail ownership

[StreamingWsola](<../../../suflyor-wsola/src/stream.rs#L22-L71>) clamps speed 0.5..3, ratio=1/speed, 30ms segment/15ms search, output crossfade 16ms rescaled per rate, ceil input overlap. Empty fresh is no-op; combines previous tail+fresh, zero-pads runt to one segment, processes, blends old held tail, withholds new tail and remembers input overlap. `finish` takes held tail once; repeated finish empty. It doesn't clear previous_input_tail or forbid a process after finish: callers own end-of-stream lifecycle. Failure returns before committing new wrapper tails; caller can fall back fresh, not native continuity proof.

[Streaming tests](<../../../suflyor-wsola/src/stream.rs#L74-L105>) check chunks finite/nonempty, empty-input no-op and 44.1k crossfade duration (706). No measured pitch artifact, transition waveform continuity threshold or allocation check. [Speech contract](<../../../suflyor-wsola/tests/speech_contract.rs#L9-L47>) uses synthetic 180Hz carrier+envelope, repeat-output determinism + same length for ratio1, speeds1/1.5/2/3 within 40ms duration tolerance and finite output. **Not input/output bit identity**: assert output equals second process output, not original input. Rust tests were not run here.

## Four native TTS transport consumers

[Windows Piper timeline](<../../../suflyor-tts/src/playback.rs#L67-L129>) stores absolute cursor/start, retains 30s played history, handles EOS vs queued data, unbounded std mpsc feed. [Windows controls/fill](<../../../suflyor-tts/src/playback.rs#L356-L423>) rewinds unread output checkpoint, clears output/stretcher, handles seek/speed; unity bypasses WSOLA, nonunity waits 16,384 fresh frames unless EOS, finish flush once, errors return raw fresh samples. [Tera Windows equivalent](<../../../suflyor-teratts/src/playback.rs#L358-L425>) same contract. Error fallback preserves samples but can temporarily change effective speed/artifact continuity; not listener pass.

[Windows render](<../../../suflyor-tts/src/playback.rs#L209-L344>) WASAPI event-loop control/pause/feed, mono duplicated stereo, silence on underrun, queued/padding drain before finish. Pause/control/native device faults/source starvation tested only by source/inline intent; no buffer-latency run. [stop/drop](<../../../suflyor-tts/src/playback.rs#L180-L203>) stop flag+join; not guaranteed instant termination under blocked native driver.

[macOS controls/fill](<../../../suflyor-tts/src/playback_macos.rs#L195-L261>) resets same WSOLA/timeline; [resampler/callback/queue](<../../../suflyor-tts/src/playback_macos.rs#L264-L439>) fractional-phase linear resampling to device rate, callback mutex VecDeque, duplicates mono across actual output channels, underrun zeros and stop/pause zeros. Worker pre-fills ~100ms and prunes timeline once source output fed to queue—not proof audible cursor aligned exactly. [Tera macOS queue](<../../../suflyor-teratts/src/playback_macos.rs#L351-L478>) analogous mutex/native sample-format branch. Not realtime lock-free claim; no CPAL/WASAPI/device listening.

## Transcript replay uses different adapter/clock

[StretchSource](<../../../slint-experiment/src/bin/overlay_host/transcript_player.rs#L60-L189>) is separate Wsola wrapper, fixed XFADE256/CHUNK16384 (16kHz-oriented), source-rate segment/search, fresh refill+tail, errors unwrap_or_default → empty stretched chunk (not transport raw fresh fallback), output clamped [-1,1]. [load/clock](<../../../slint-experiment/src/bin/overlay_host/transcript_player.rs#L263-L320>) unity bypasses direct PCM, nonunity allocates adapter, wall-clock elapsed×speed estimates original position. [seek/speed](<../../../slint-experiment/src/bin/overlay_host/transcript_player.rs#L350-L415>) rebuilds from estimated source sample, keeps UI clock; not direct playback device consumed-frame count. Drift/time-to-first sample/source callback allocation/seek sound unaccepted.

[Test intent](<../../../slint-experiment/src/bin/overlay_host/transcript_player.rs#L533-L584>) checks time speed scaling, PCM cursor conversion, speed clamp, empty playback error; real rodio output smoke **ignored** requiring audio device. Six new Python tests check source tokens/order only, no reimplementation of WSOLA numerical algorithms, native allocation/pitch/cancel quality or independent acceptance. Original claim statuses unchanged, all other UI/model/test branches remain partial.
