# Startup, wizard, health and diagnostics: bounded source contract

**Evidence:** manually inspected principal sources/callers at frozen baseline `a10c356af05a5832a14ea06a5d0cb6c49694e3f1`. No app start, device/network probe, Windows/macOS build, UI screenshots, real config/log or native acceptance. Not all startup callbacks, configuration keys or error paths.

## Preflight and startup

[Thin entrypoint](<../../../slint-experiment/src/bin/overlay_host.rs>) includes the shared platform root. [Main](<../../../slint-experiment/src/bin/overlay_host_windows.rs#L474-L503>) calls [preflight](<../../../slint-experiment/src/bin/overlay_host/app_bootstrap.rs#L13-L70>) before config/window construction, retaining singleton guard and Tokio runtime. Order: migrate data root → initialize logging → acquire singleton → repair unfinalized recordings → build two-worker Tokio runtime → first-run snapshot. Another-instance/error exits via `Ok(None)`; runtime failure returns platform error, not a usable AI-disabled GUI despite its log wording.

[Data migration](<../../../overlay-backend/src/paths.rs#L24-L119>) prefers new data directory, falls back to legacy when migration fails, and uses rename rather than merging existing directories. Windows [named mutex](<../../../slint-experiment/src/native/windows/lifecycle.rs#L7-L56>) releases with guard lifetime; macOS [per-user file lock](<../../../slint-experiment/src/native/macos/lifecycle.rs#L13-L51>) leaves its inode on disk and polls every 50ms on contention. Normal start waits zero, `--relaunch` up to 8s. Repair is best effort before config/UI, not proof of crash recovery or session supervisor restart.

`first_run` means **config path does not exist before config load**, not `wizard_done == false`. Path-resolution failure defaults false. [Auto system capture](<../../../slint-experiment/src/bin/overlay_host_windows.rs#L4609-L4644>) fires after 400ms; on macOS failure resets the UI toggle, on Windows it invokes system-toggle dispatch. [First-run wizard](<../../../slint-experiment/src/bin/overlay_host_windows.rs#L4647-L4670>) runs after 2200ms **only on Windows**. The wizard module/import and first-run branch are Windows-cfg-gated; there is no auto wizard in the reviewed macOS branch. Existing configs skip the auto wizard irrespective of `wizard_done`; [manual Settings callback](<../../../slint-experiment/src/bin/overlay_host/settings_controller.rs#L456-L469>) opens it separately. Recovery environment-path starts only when `!first_run` [after 2500ms](<../../../slint-experiment/src/bin/overlay_host_windows.rs#L4676-L4708>).

## Windows wizard: state, checks and completion

[Wizard navigation](<../../../slint-experiment/src/bin/overlay_host/wizard.rs#L77-L147>) advances steps 0..6, Next triggers AI/STT/mic/sys checks, Skip does not, both refill step-7 summary. [Finish/cancel handlers](<../../../slint-experiment/src/bin/overlay_host/wizard.rs#L438-L488>) hide and clear the slot; no `wizard_done` setter/save exists in this module. Selecting mode [writes provider fields and attempts save](<../../../slint-experiment/src/bin/overlay_host/wizard.rs#L118-L147>), logging failure; successful save creates the config and prevents the next automatic first-run wizard even if setup is cancelled. Skips/errors do not gate completion; this is guided setup, not enforced readiness. [Opener](<../../../slint-experiment/src/bin/overlay_host/wizard.rs#L422-L488>) re-focuses an existing active wizard without resetting steps/results, otherwise creates a fresh window with [UI default step 0](<../../../slint-experiment/ui/wizard.slint#L119-L152>); finish/cancel clear the slot so subsequent opens reconstruct it. Window registry and stealth-aware native presentation are reused.

[AI/STT checks](<../../../slint-experiment/src/bin/overlay_host/wizard.rs#L150-L226>) resolve active configuration, spawn threads with throwaway runtimes, set level -1 while pending and update via UI event-loop closures. AI formatted error chain (apart from deep-lock blocked copy) / STT raw error chains are truncated to 80 chars, not scrubbed here. [Backend AI probe](<../../../overlay-backend/src/ai/inspect.rs#L20-L129>) hides ordinary transport URL/host behind failure categories, but exposes truncated protocol response error/body; Codex and MLX paths differ. [STT probe](<../../../overlay-backend/src/stt.rs#L126-L217>) is heterogeneous: Groq models HTTP request, Whisper server `/health`, GigaAM filesystem model/vocab existence. Therefore green STT test does not prove transcription/model load/audio-to-text. No fixture here establishes all error-chain privacy.

[Mic check](<../../../slint-experiment/src/bin/overlay_host/wizard.rs#L229-L277>) acquires shared RAII mic guard on UI thread, records 3s, releases before result processing; busy/empty/device error fails, quiet captured audio succeeds even below -45dBFS. [System check](<../../../slint-experiment/src/bin/overlay_host/wizard.rs#L279-L313>) plays a test tone/captures loopback and requires >-60dBFS. [Wizard local-install/diagnostic shortcuts](<../../../slint-experiment/src/bin/overlay_host/wizard.rs#L316-L378>) open Settings tabs 2/10. [Wizard stealth](<../../../slint-experiment/src/bin/overlay_host/wizard.rs#L381-L419>) persists runtime/config intent, logs save errors and applies registry-wide effective state. Checks are asynchronous without an inspected generation token; whether close/reopen/repeated checks cause stale completion is untested.

[Summary picker](<../../../slint-experiment/src/bin/overlay_host/wizard.rs#L35-L57>) intentionally avoids `ReadinessItem.detail` (contains endpoint/path), choosing existing live-check detail or `configured`/dash. However copying previously raw test detail is not evidence of fully redacted privacy. Source comments saying “secret-free” do not close that acceptance gap.

## Config readiness versus diagnostics live checks

[Config::readiness](<../../../overlay-backend/src/config.rs#L957-L1068>) is config-only: active AI requires model/url and bearer unless local/Codex; GigaAM only nonempty directory; Whisper only nonempty URL; cloud STT nonempty key; mic/system default device always configured; vision model/url but not bearer. It performs no network/audio/model-load test. Details include provider/model/endpoints/path/device, not bearer itself.

[Population](<../../../slint-experiment/src/bin/overlay_host/diagnostics.rs#L33-L62>) copies those details directly into Diagnostics and maps AI/STT configured → 0, absent → 2; vision configured → 0/off → 3; mic/system are neutral 3 until live samples. Stealth uses effective OS state. [Settings new/reused paths](<../../../slint-experiment/src/bin/overlay_host/settings_controller.rs#L105-L166>) repopulate on open; successful live-probe detail is not durable current health. Generic screen-share privacy of all readiness details is **not established**: the code copies endpoint details directly. Report/log redaction is a distinct path, not automatically applied to readiness/UI errors.

[Check-all](<../../../slint-experiment/src/bin/overlay_host/diagnostics.rs#L511-L683>) sets pending levels, snapshots active endpoints/backends/devices, runs sequential AI/STT/vision probes on a worker current-thread runtime, then mic and system tone capture. [Vision test](<../../../overlay-backend/src/vision.rs#L242-L247>) sends synthetic image, never captures real screen. AI/vision deep-lock failures get dedicated blocked text; other chains truncated, not redacted at this caller. Mic guard prevents simultaneous capture and quiet capture is success. Callbacks use weak UI refs but no generation gating found in reviewed handler; native timing is untested. Stale comment that mic/sys stay config-only is contradicted by current executable handler.

## Session health counters and UI

[HealthSignals snapshot](<../../../overlay-backend/src/health.rs#L60-L136>) uses atomics: audio/mic degraded at 15s/down at 60s, STT 60s/180s, AI 180s/600s; zero timestamp → idle. Shared audio folds worst mic/shared state. Latest nonzero AI error timestamp >= last AI success forces down immediately, separate from age. Labels are staleness/last-result signals, not end-to-end engine readiness.

[Session initialization](<../../../slint-experiment/src/slint_session.rs#L310-L333>) clears audio/STT/AI/error and seeds mic start timestamp so dead mic can degrade even when no frames arrived. [Capture gate](<../../../slint-experiment/src/slint_session.rs#L604-L642>) bumps shared/mic timestamps before pause/mute drops and STT/recorder submission. [Session emitter](<../../../slint-experiment/src/slint_session.rs#L521-L574>) ticks every 2s, Skip missed ticks, overrides paused/off/muted sources to idle and configured-disabled AI to idle before `health:update`. [Stop](<../../../slint-experiment/src/slint_session.rs#L1411-L1446>) aborts health task and zeros counters; explicit terminal health emit follows. [Bar event bridge](<../../../slint-experiment/src/bin/overlay_host/tile_controller.rs#L858-L921>) maps state labels to 0/1/2/3, forces off/mute audio idle and gates the visible AI-down status marker on `timer_active` to reject queued down state (not a blanket AI-dot idle override). Native event ordering/counter correctness remains untested here.

## Diagnostic report and log redaction

[Report](<../../../slint-experiment/src/bin/overlay_host/diagnostics.rs#L307-L381>) includes config-readiness, version, requested/effective stealth, GPU cache, hotkey states and optional short errors; redacts home, URLs, IPv4 and recognized credential patterns before return. [GPU cache](<../../../slint-experiment/src/bin/overlay_host/diagnostics.rs#L247-L302>) is primed once on worker, Windows PowerShell command hidden; pending reads don't run WMI on UI thread. [Report copy callback](<../../../slint-experiment/src/bin/overlay_host/diagnostics.rs#L393-L405>) sends rendered report to clipboard, not raw config.

[URL redaction](<../../../slint-experiment/src/bin/overlay_host/diagnostics.rs#L110-L140>) masks hosts but retains scheme/port/path; [IPv4 redaction](<../../../slint-experiment/src/bin/overlay_host/diagnostics.rs#L65-L108>) recognizes four numeric octets. [Credential-pattern redactor](<../../../slint-experiment/src/bin/overlay_host/diagnostics.rs#L143-L181>) additionally masks exact `Bearer `, `gsk_`, `sk-` prefixes until selected delimiters. These passes are not proof of exhaustive unknown credential/query/path/bare-IPv6 scrubbing. [Log export](<../../../slint-experiment/src/bin/overlay_host/diagnostics.rs#L724-L755>) reads whole log, applies same passes, writes dated copy to Desktop (data-root fallback), including recognized credential prefixes, but no proof of exhaustive structured-secret sanitization. [UI callback](<../../../slint-experiment/src/bin/overlay_host/diagnostics.rs#L685-L722>) runs off thread and shows home-masked path/generic failure. No real log was accessed or exported by this research.

## Acceptance boundaries

Open: all startup timers/background processes, Windows/macOS startup faults, wizard persistence/generation races, config-key/translation/assets schema, complete error privacy and physical-native validation.
