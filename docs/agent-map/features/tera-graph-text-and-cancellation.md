## Text/indexer/style chain and limits

[Utterance chunker](<../../../suflyor-teratts/src/chunk.rs#L5-L79>) sanitizes controls, splits punctuation/words at target120chars. `hard_split` preserves whole words; **single oversized word can exceed120**, so comment isn't a hard upper bound on work/memory. Empty text no jobs. [ensure/prepare](<../../../suflyor-teratts/src/textnorm.rs#L22-L56>) adds ru/en default tags only when no substring tag, NFC → punctuation/number-word spacing → unsupported skip → tag validation → tagged number expansion → NFKD/strip stress for duration. Manual `+` passed for encoder but removed duration, no neural RUAccent orchestration.

[Tag stack](<../../../suflyor-teratts/src/textnorm.rs#L170-L249>) permits nested matching tag pairs by stack; rejects unclosed/mismatch/unknown language, leaves other angle text. [Span discovery/expansion](<../../../suflyor-teratts/src/textnorm.rs#L256-L318>) sorts closing spans by start and slices `cursor..content_start`. Nested parent+child overlapping spans are a **source-only precondition concern**: validation permits nesting but expansion assumes nonoverlapping cursor order. Not proven accepted reference parity/panic/repro; no Python clone/run claimed as Rust behavior. [Number matcher](<../../../suflyor-teratts/src/textnorm.rs#L321-L359>) ASCII signed integer/decimal boundaries/backtracking; [number words](<../../../suflyor-teratts/src/num2words.rs#L7-L45>) bounded u64 parse/default unsupported language, not all linguistic numeral declensions.

[Indexer](<../../../suflyor-teratts/src/indexer.rs#L16-L75>) requires table65536, drops unsupported BMP/nonBMP during skip, encode maps text to i64 IDs/mask and reports U+code not whole input. NFKD follows skip, so decomposed combining characters can newly fail encode; tests synthetic table intentionally supports them, not actual loaded tokenizer pass. [NPY](<../../../suflyor-teratts/src/npy.rs#L16-L79>) reads whole style file, magic/version1/2, rejects Fortran order, f4/f8 little endian, shape `.product()`/element-byte multiply/capacity **unchecked**, no comprehensive malicious-header memory bound. Exact expected style shape [load_style](<../../../suflyor-teratts/src/tera.rs#L308-L318>) checked **after** parsing/allocating; installer-pinned assets reduce but don't test hostile same-size replacement precondition.

## Graph inference work and causal vocoder chunks

[Synth inputs/encoder/duration](<../../../suflyor-teratts/src/tera.rs#L143-L225>) two indexer texts, style shapes[1,50,256]/[1,8,16], embedding named output generic shape, duration must have one finite positive value. Duration scale applied/clamped minimum0.01 but no explicit maximum clip duration/frame-budget; latent ceil(seconds×44100/3072)≥1. [Sampler](<../../../suflyor-teratts/src/tera.rs#L211-L257>) allocates [1,24,F] noise unbounded product before tensor shape checks, eight deterministic step/cfg3 updates; native memory/work/NaN scale/style risk unresolved.

[Vocoder loop](<../../../suflyor-teratts/src/tera.rs#L259-L305>) uses16-frame new chunks with20 left-context, [channel-first slice](<../../../suflyor-teratts/src/tera.rs#L321-L345>) validates latent shape/window and copies each channel; [vocoder shape](<../../../suflyor-teratts/src/tera.rs#L423-L449>) rank2/3 batch1 mono and sufficient samples before slicing overlap discard. Trim to floor(seconds×44100); chunks all accumulated into `SynthOutput {chunks}`. **Not incremental event streaming during one synthesis call**: per text chunk inference/vocoder completes before first result sent to controller. “Streaming” means causal-window decomposition and between text-chunk playback, not proof time-to-first16frame latency.

## Generation cancellation stops playback/discards results, not active ORT run

[Controller close/speak](<../../../suflyor-teratts/src/main.rs#L210-L293>) stops/join player, zeros active counters/generation, Done previous; creates utterance/player and enqueues all text chunks. [Synth worker](<../../../suflyor-teratts/src/main.rs#L462-L501>) checks generation **before** job, catch_unwind synthesizes, then sends full output; TeraEngine has no generation callback/inference terminate token. STOP/new Speak can be processed on protocol controller while stale ORT job continues to finish; stale returned audio [on_synth_result](<../../../suflyor-teratts/src/main.rs#L295-L364>) discarded by active id. No instantaneous compute/CPU/memory cancellation claim.

[Channel setup](<../../../suflyor-teratts/src/main.rs#L575-L629>) unbounded mpsc commands/synth jobs/events, loaded engine moved to synthesis worker; failed engine dispatch maps coarse not-installed/synth token. Multiple/stale jobs skip after dequeue, but unbounded queued text memory/dispatch-failure `chunks_total` bookkeeping/runtime races untested. Partial synth errors drain good audio, all errors terminal Failed; playback callback late ids dropped. [EOF](<../../../suflyor-teratts/src/main.rs#L648-L663>) sends Shutdown; controller close stops audio. Synth thread owned implicitly process lifetime, not joined/aborted in this reviewed EOF path.
