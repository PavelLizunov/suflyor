suflyor v0.36.1-rc.3 — ретест

Проверять установленную сборку. Для каждого пункта отметить результат и при ошибке записать шаги воспроизведения.

1. Версия установлена В Настройки → Обновления показано 0.36.1-rc.3; в Windows Apps & features версия совпадает.
2. Значок глубокой блокировки по центру Выбрать управляемый локальный ИИ и вторым кликом по замку включить красную глубокую блокировку. В полном и компактном баре значок замка расположен по вертикальному центру красного chip рядом с подписью Локальный ИИ выгружен / Local AI unloaded, а не у верхней границы.
3. Полный сценарий глубокой блокировки При пустом транскрипте нажать F6 и «+ тайл»: показано сообщение о заблокированном/выгруженном локальном ИИ, а не «Транскрипт пустой». Третий клик по замку запускает модель и снимает блокировку только после готовности.
4. Базовый smoke Start/Stop, F1, F4, F6, F9, полный/компактный бар и Quit работают; рядом с приложением есть DirectML.dll.
