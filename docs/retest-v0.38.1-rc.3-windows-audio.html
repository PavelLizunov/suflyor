suflyor v0.38.1-rc.3 — ретест аудиоустройств Windows

Чек-лист ретеста для фикса выбора устройств захвата звука в Windows.
ВАЖНО: тестируй УСТАНОВЛЕННЫЙ билд (setup.exe → запуск), версия = 0.38.1-rc.3.
Селектор микрофонаfeature
RUENШаги: Открыть Настройки > Аудио. Раскрыть выпадающий список «Микрофон».
Ожидание: Первый пункт — «По умолчанию Windows» («Windows default»), далее список доступных физических микрофонов.
Селектор системного звука (наушники / динамики)feature
RUENШаги: Открыть Настройки > Аудио. Раскрыть выпадающий список «Системный звук — наушники / динамики».
Ожидание: Первый пункт — «По умолчанию Windows», далее доступные устройства вывода (динамики, наушники) и capture-миксы гарнитур (напр. A50 Stream Out).
Смена гарнитуры / default endpointP0
Шаги: При выбранном «По умолчанию Windows» переключить аудиоустройство в Windows или переподключить гарнитуру. Запустить сессию захвата.
Ожидание: Захват автоматически следует за текущим системным устройством Windows по умолчанию.
Закрепление конкретного устройстваfeature
Шаги: Выбрать конкретные наушники/микрофон в списке. Перезапустить Настройки.
Ожидание: Выбранное устройство сохраняется и остаётся выбранным в выпадающем списке.
Отображение недоступного сохранённого устройстваP1
Шаги: Отключить сохранённое ранее USB-устройство. Открыть Настройки > Аудио.
Ожидание: Название отключённого устройства сохраняется в выпадающем списке, отображается предупреждение: «Сохранённое устройство недоступно. Выберите другое устройство или По умолчанию Windows».
Кнопка «Обновить устройства»feature
Шаги: Подключить новое USB-аудиоустройство и нажать «Обновить устройства».
Ожидание: Список обновляется в фоновом потоке, появляется новое устройство; интерфейс не зависает.
Применение изменений к следующему захватуfeature
Шаги: Сменить устройство захвата во время или между сессиями. Проверить сообщение о перезапуске сессии.
Ожидание: Отображается подсказка: «Выбор применяется при следующем запуске захвата. Если сессия уже идёт, остановите и запустите её заново». При новой сессии используется новое устройство.
