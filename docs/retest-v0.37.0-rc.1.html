suflyor v0.37.0-rc.1 retest — experimental TeraTTSv2 read-aloud engine

  1. Start from the SAFE state: engine Piper (default), at least one Piper voice installed. Confirm Settings → Read aloud shows the Engine chooser with "Piper" selected and the Piper voice/speed/test controls unchanged from rc.16; read-aloud from a tile still speaks through Piper.
  2. Switch Engine to "Tera (experimental)". The tab must show the EXPERIMENTAL warning, a model status line ("not installed"), Install model + Cancel buttons, and NO Tera voice dropdown yet. Config persists: reopen Settings — Tera is still selected.
  3. Install the Tera model: phases advance (Preparing / Downloading file (i/N) / Verifying / Publishing / Model installed). Cancel mid-download once: the run stops, status shows cancelled, and a retry resumes to completion. After success the status flips to installed+ready and the ten Tera voices appear; restarting the app keeps the installed state (%APPDATA%\suflyor\tts\teratts-v2-<revision>).

  5. Fallback: with engine Tera selected, delete/rename the teratts-v2-<revision> dir (or the suflyor-teratts.exe) and read aloud again — speech must still play through Piper without a restart decision from the user; no crash, no silent failure.
  6. Diarization stays independent: run "Определить говорящих" on a recorded session with engine Tera selected — it must complete through the Piper sidecar (suflyor-tts.exe) exactly as before.
  7. Persistence + compatibility: an rc.16 config (bare tts_voice, no tts_engine) must open on Piper with the same voice; after choosing a Tera voice, config.json stores "tera:<style>" and engine "tera".

  9. Resolution matrix: at 1280x768 and 720x600, in English and Russian, the Read aloud tab (both engine sections, install phases, status lines) renders without clipping or missing glyphs.
  10. Logs: %APPDATA%\suflyor\suflyor-teratts.log exists after Tera speaks and contains ids/counts only — never the spoken text; overlay-host log shows the Tera READY handshake line and no URLs with credentials.
  11. P1 hardening — self-healing install: with the model installed, damage the release dir (truncate one file under models\ or delete its manifest.json), then press Install model again. The run must NOT fail forever at Publishing: the broken dir is moved aside (teratts-v2-<revision>.broken-*), the fresh copy publishes, status flips to installed+ready, and Tera speaks. A valid install must never be re-downloaded or touched.

P1 hardening — STOP/interrupt during synthesis: with Tera selected, read a LONG tile answer aloud and press stop while speech has not started yet or is mid-first-chunk (synthesis still running). Audio must stop IMMEDIATELY — no waiting for CPU synthesis. Likewise start a NEW read-aloud while the previous one is still synthesizing: the old utterance is replaced and none of its audio ever plays. Every interruption still shows exactly one terminal state on the tile.
  13. P1 hardening — dead engine never falsely suppresses the mic: with Tera selected, make the engine unusable (rename the model dir AND suflyor-teratts.exe) and read aloud. STOP with a dead sidecar must not spawn a new engine process.
