# Suflyor v0.38.1-rc.8

This release candidate is v0.38.1-rc.7 plus four layout fixes (pull request #258). It changes no layout, colour or text of the interface.

## Fixes

- **Answer tile**: the status pill ("AI · done", "error") sat 5 px above the title and the buttons. It is centred on the header row.
- **Settings > Components**: the state dot sat in the top corner of its row. It is centred on the row.
- **Settings > AI providers**: with the custom or the local vision bridge, "Test vision connection" overlapped the last field. The gap equals the one between the fields.
- **Settings > Hotkeys**: the second line of the Shift+F9 description was cut off. It is shown in full.

## Known, not fixed here

- Settings > Profile: the gaps around the description are uneven.
- Everything listed as known in the v0.38.1-rc.7 notes.

## Installers

- Windows 10/11: `suflyor-slint-setup.exe`.

The Windows installer is unsigned.
