suflyor v0.38.0 — Windows + macOS acceptance

Release checklist for the first dual-platform stable build.

  1. Windows: installer upgrades cleanly, overlay opens, hotkeys and clean quit work.
  2. macOS: arm64 app installs at a stable path, opens, and keeps the menu-bar/overlay surfaces alive.
  3. macOS STT: managed GigaAM is the primary recognizer and transcribes Russian speech. An existing managed model is detected automatically; a missing model has Download / Resume, MB progress, and Cancel.
  4. macOS local AI: MLX setup cards appear only for the selected MLX provider. LFM2.5-8B-A1B text and Qwen3.5-2B Vision use left-anchored MB progress, install, activate, and answer.
  5. macOS Vision: Screen Recording denial is visible; granting access plus a full relaunch enables F8 capture.
  6. macOS TeraTTS: speech starts promptly, plays without stalls, and the sidecar exits with the app.
  7. macOS Audio: Settings shows the current default input; microphone and one-owner system capture continue after default-route changes, including AirPods.
  8. macOS STT latency: live recognition forces 10-second slices and flushes after 800 ms of silence.
  9. macOS Managed MLX: native Swift/Metal prewarm starts in the background and automatic answers use the verified 4096-token output budget.
  10. macOS telemetry: Full mode shows App RAM / RAM приложения and short MLX memory below the model label, plus measured load, TTFT, total, decode, and end-to-end values that expire after 30 seconds; no VRAM label appears.
  11. macOS Stealth: Settings states that capture exclusion is unsupported without promising hidden windows.
