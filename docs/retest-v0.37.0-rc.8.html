suflyor v0.37.0-rc.8 - hidden-to-tray mode

  1. Start suflyor. The bar must always start visible; hidden state must not survive a restart.
  2. Verify the Hide to tray chip appears beside the compact-bar control in both wide and compact layouts, with no clipping at 1280 px and no tofu glyphs.
  3. Start a session, open a tile, begin TTS, then choose Hide to tray. Only the bar disappears; the tile, recording, TTS, timer, and global hotkeys continue working.
  4. Left-click the suflyor tray icon. The bar returns without changing compact mode, size, monitor, always-on-top behavior, or focus unexpectedly. Left-click again to hide it.
  5. Right-click the tray icon. Verify Restore/Hide, Pause/Resume, Stop, and Quit labels follow the selected RU/EN UI language and disabled/checked states match the running session.
  6. Use Pause/Resume and Stop from the tray menu. They must behave exactly like the existing bar controls; Stop must never start an idle session.
  7. With the bar hidden, restart Windows Explorer. The tray icon must return and still restore the bar. If icon recovery fails, the bar must become visible automatically.
  8. Run the normal screenshot hotkey while the bar is hidden. The bar must remain hidden after the capture cycle; other hotkeys must remain registered.
  9. Quit from the tray menu. Recording and sidecars must follow the normal clean shutdown path, and no duplicate or stale tray icon should remain after relaunch.
