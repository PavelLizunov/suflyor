# План: Шаг 6 — Автоматизированный аудит интерфейса через Slint MCP (MCP UI Matrix)
Ветка: `codex/mcp-ui-matrix-audit`
Цель: Реализовать автоматизированный аудит интерфейса по методологии VPNRouter (Шаг 7): проверка окон, 16 вкладок настроек, цветовых тем, локализации и выявление дефектов вёрстки (обрезанный текст, некорректные статусы).

## Архитектура инструмента (scripts/slint-mcp-matrix-audit.py):
1. Подключение к встроенному серверу Slint MCP (`http://127.0.0.1:<PORT>/mcp`).
2. Опрос списка окон (`list_windows`).
3. Для каждого окна и вкладки:
   - Проверка наличия элементов интерфейса.
   - Снятие снимка экрана (`take_screenshot`).
   - Проверка корректности текстовых меток (отсутствие эмодзи вместо SVG, отсутствие `[err]` или некорректных статусов).
4. Формирование отчёта `docs/mcp-ui-audit-report.md`.

## Как проверяем:
1. Запуск синтаксической проверки скрипта аудита Python.
2. Проверка интеграции со сборкой `--features ui-mcp`.
3. Документирование результатов в `CURRENT_STATE.md`.
